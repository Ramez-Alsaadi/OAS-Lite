OAS Lite – Offline Attendance Management System

Project Overview

OAS Lite is a web-based attendance management system built with Java and Spring Boot.

The project aims to simplify employee attendance tracking and address operational challenges such as unreliable internet connectivity and attendance recording issues.

This project is being developed as a practical portfolio project, with a focus on secure web application development.

Technologies Used

- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- Thymeleaf
- H2 Database
- HTML
- CSS
- JavaScript
- Maven
- Git & GitHub

Current Features

- Employee management.
- Employee registration and management.
- Attendance check-in and check-out.
- Prevention of duplicate check-in operations.
- Prevention of invalid check-out operations.
- Employee active/inactive status handling.
- Attendance dashboard.
- Arabic and English interface.

Development Roadmap

- Complete offline attendance recording.
- Implement reliable synchronization when connectivity is restored.
- Improve authentication and authorization.
- Perform Web Application Security Testing.
- Test API endpoints and access control.
- Document security findings and remediation.

Application Security Focus

Application security is an important part of this project's development.

Planned security activities include:

- Authentication and session security testing.
- Authorization and access control testing.
- Input validation testing.
- API security testing.
- Security testing using Burp Suite.
- Vulnerability documentation and remediation.

GRC Supporting Activities

Governance, Risk, and Compliance (GRC) practices will support the application security work through:

- Maintaining a security risk register.
- Assessing application security risks.
- Mapping relevant security risks to applicable NCA Essential Cybersecurity Controls (ECC).
- Documenting security controls and remediation evidence.

This project does not claim NCA compliance or certification.

Project Status

Status: Under Development

OAS Lite is an educational and portfolio project. Some planned features and security assessments are still in progress.
